# member-info-v1 문구 검토 및 반영 경계

## 이 파일들의 역할
- `terms.html`: 기존 이용약관의 승인된 회원가입 관련 조항 **교체안**. 전체 약관 대체본이 아니다. 조항 번호는 기존 root/terms.html 기준으로 유지했다.
- `privacy.html`: 승인된 수집항목과 실제 구조를 반영한 개인정보처리방침 **개정안**. 미확정 사실은 눈에 띄게 표시했다.
- 공개 root/terms.html·privacy.html, 메인 메뉴, 운영 서버 문서 URL·버전은 이 PR에서 바꾸지 않는다. 이 폴더는 컨테이너 이미지에 포함되거나 서비스 라우트로 노출되지 않는다. `noindex`는 비공개 보안장치가 아니다.
- `backend/signup_views.py`에는 동의 전에 열람할 항목·목적·기간·거부 안내가 있고 필수/선택 체크가 분리되어 있다. 추가 수집은 두 정책 버전을 `member-info-v1`으로 명시해야만 활성화된다.

- 개인정보 보호법15조: https://www.law.go.kr/법령/개인정보보호법/제15조
