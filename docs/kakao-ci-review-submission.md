# Kakao CI 개인정보 동의항목 재심사 제출안

기준: 2026-09-28 카카오디벨로퍼스 개인정보 동의항목 심사 체크리스트.

## 신청 동의항목

- 이름: 필수
  - 목적: 회원 확인 / 수강생 관리 / 상담 대상 확인
- 카카오계정(전화번호): 필수
  - 목적: 회원 서비스 안내 / 상담 연락
- CI(연계정보): 필수
  - 목적: 동일인의 중복 회원가입 방지 / 기존 회원 비교 식별
  - 처리: CI 원문은 저장하지 않고 서버에서 SHA-256 단방향 변환 후 비교키로만 보관
  - 제한: 로그인 회원번호 또는 자체 본인인증 수단으로 사용하지 않음
- 성별: 선택
  - 목적: 상담정보 수집 동의 시 상담 준비 / 분석
- 연령대: 선택
  - 목적: 상담정보 수집 동의 시 상담 준비 / 분석

이메일은 일반 카카오 로그인 동의항목에서 별도 설정하며, 이번 추가 기능 신청 항목과 혼동하지 않는다.

## 회원가입 경로

1. 리치온아카데미 회원 영역 진입
2. 카카오 로그인 선택
3. 카카오 로그인 / 동의 화면
4. 리치온아카데미 회원정보 완료 화면
5. 필수/선택 동의 후 가입 완료
6. 마이페이지
7. 마이페이지 > 계정 관리 > 회원탈퇴

## 회원정보 완료 화면의 표시 조건

- 이름: 필수
- 휴대전화번호: 필수
- 이메일: 필수
- CI(연계정보): 필수(카카오 회원가입)
- 연령대: 선택
- 성별: 선택
- 만 14세 이상: 필수
- 이용약관: 필수
- 개인정보 수집·이용: 필수
- 광고성 정보 수신: 선택

CI 권한 승인 전에도 카카오 회원가입 화면에서 CI가 카카오 가입 필수 항목이며
'동일인의 중복 회원가입 방지 및 기존 회원 비교 식별' 용도라는 사실이 표시된다.
승인 후 실제 CI가 반환된 경우에는 '카카오에서 확인 완료' 상태가 함께 표시된다.

## 서버 실제 사용

- Kakao user/me 요청에 kakao_account.ci 포함
- CI raw value는 provider adapter에서 즉시 SHA-256 digest로 변환
- oauth_signups에는 digest만 임시 저장
- member_ci_claims.ci_digest UNIQUE
- 동일 CI로 다른 member_id 생성 시 가입 실패
- 탈퇴 시 member_ci_claims 삭제

개인정보가 들어간 실제 사용자 화면은 제출하지 않는다.

   - 이름 필수

5. 가입 완료 후 마이페이지
6. 계정 관리 / 회원탈퇴 경로
7. 개인정보처리방침의 동일 항목/목적 부분

## 신청 사유 문안

리치온아카데미는 카카오 간편로그인을 회원가입 수단으로 사용합니다.
한 사용자가 서로 다른 카카오 계정 또는 향후 연결되는 로그인 수단을 통해 중복 회원으로 생성되는 것을 방지하고,
기존 회원과 동일인 여부를 비교 식별하기 위해 CI(연계정보)를 필요로 합니다.
CI는 회원 비교 식별을 위한 최소 목적에만 사용하며 본인인증이나 로그인 회원번호를 대체하지 않습니다.
서비스 서버는 카카오에서 전달받은 CI 원문을 저장하지 않고 즉시 SHA-256 단방향 변환한 값만 보관하며,
동일 변환값의 중복 회원 생성을 차단합니다. 회원탈퇴 시 해당 비교키를 삭제합니다.
