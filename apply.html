강의 신청

현재 모집 상태를 확인한 뒤 신청해 주세요. 모집 예정 과정은 신청/결제 버튼을 열지 않습니다.

  • ✓과정별 일정과 운영 방식은 신청 안내에서 최종 확인합니다.
  • ✓신청 정보와 결제 정보는 실제 운영 링크가 열린 뒤 입력합니다.
  • ✓접수 확인 후 수강 방법과 준비사항을 별도로 안내합니다.

신청 흐름

  1. 1
    과정과 모집 상태 확인 / 모집중, 대기신청, 모집예정을 먼저 구분합니다.
  2. 2
    신청서 제출 / 결제 / 실제 운영 링크가 연결된 과정만 신청 또는 결제를 진행합니다.
  3. 3
    수강 안내 확인 / 접수 확인 후 일정과 참여 방법을 안내합니다.
선택한 과정

현재는 UI 준비 상태입니다. 실제 신청/결제 링크가 설정되기 전에는 버튼이 비활성화됩니다.
