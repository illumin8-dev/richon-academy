# member-info-v1 문구 검토 및 반영 경계

## 이 파일들의 역할
- `terms.html`: 기존 이용약관의 승인된 회원가입·계정 관련 조항 **교체안**. 전체 약관 대체본이 아니다.
- `privacy.html`: 승인된 수집항목·계정 생명주기·국외처리 방향을 반영한 개인정보처리방침 **공개 전 최종 검토안**이다.
- 공개 root `terms.html`·`privacy.html`은 이 초안으로 통째로 덮어쓰지 않는다.
- 최종 병합 기준은 **실제 공개 root 파일의 최신 버전**이며, 이 폴더에서 승인된 교체 조항만 해당 위치에 통합한다. 기존 공개 문서의 무관한 조항은 보존하고, 서로 충돌하거나 실제 제공하지 않는 기능을 전제로 한 문구만 별도 검토한다.
- 메인 로그인/마이페이지 공개 여부, 정책 공개, 기능 활성화는 각각 별도 단계다.

## 국외처리 조사 반영
### Google Cloud
- 대한민국 청구주소의 Google Cloud Platform 계약 주체는 공식 계약 페이지상 Google Cloud Korea LLC로 안내된다. 실제 계정의 청구주소·계약조건은 공개 직전 최종 대조한다.
- 현재 리치온 Cloud Run 주 리전은 `asia-southeast1`(Singapore).
- Google Cloud는 글로벌 서비스·하위처리자 구조를 사용하므로 모든 처리가 Singapore에만 한정된다고 쓰지 않는다.

### Neon
- 2026-09 실제 production 프로젝트 확인: platform AWS / `aws-ap-southeast-1` / production default branch / history retention 86400초(1일).
- 2026-08 Neon Product Specific Schedule은 Databricks, Inc.와 고객의 Neon 제품 사용을 규율하고 Neon, LLC가 일부 청구를 수행할 수 있다고 설명한다.
- 데이터베이스 정본은 Singapore 리전이지만 DPA/하위처리자의 글로벌 운영 가능성을 별도 고려한다.

### Cloudflare
- Cloudflare DPA의 처리자는 Cloudflare, Inc.
- 별도 Customer Metadata Boundary를 적용하지 않으면 Customer Logs가 글로벌 core data center에 저장될 수 있다.
- Zero Trust/Access 로그 보유기간은 제품·요금제별로 다르므로 실제 리치온 계정 요금제와 설정을 공개 직전 최종 대조한다.
- HTTP request log retention은 제품별 설정이 다르므로 모든 Cloudflare 로그에 하나의 보유기간을 임의 적용하지 않는다.

## 광고성 정보 수신동의 구현 경계
정책 결정은 승인됐지만 **운영 구현은 아직 아니다**.
공개 전에 다음이 필요하다.
1. 가입 UI에 [선택] 광고성 정보 수신 동의 추가.
2. 전체 동의는 선택 편의기능으로 제공하되 광고동의 개별 해제 가능.
3. 광고동의 여부/동의시점/철회시점과 수신채널을 별도 저장.
4. 미동의 회원에게 광고성 메시지를 보내지 않도록 발송 경로에서 확인.
5. 야간 광고성 전송을 사용하지 않는 운영원칙 유지. 필요해지면 별도 동의 설계를 다시 검토.
